# CLI Redesign: argparse to Typer

## Summary

Replace argparse-based CLI with Typer. Move from mutually exclusive flags to proper commands. Separate CLI declarations from business logic.

## Current Problems

- 5 mutually exclusive `--flags` instead of commands
- Manual argument validation (`validate_args()`)
- Awkward compound flags (`--import-deck`, `--export-deck`)
- CLI declarations and business logic mixed in one 400-line file

## Command Structure

### Before

```
kards --sync
kards --export --format xlsx --file cards.xlsx
kards --update --file cards.xlsx
kards --import-deck --file deck.txt
kards --export-deck --file deck.xlsx
```

### After

```
kards sync
kards export --format xlsx --file cards.xlsx
kards update --file cards.xlsx
kards deck import --file deck.txt
kards deck export --format xlsx --file deck.xlsx
kards --version
```

Auto-generated by Typer:
```
kards --help
kards sync --help
kards deck --help
```

## File Handling Rules

| Command | `--format` | `--file` | File behavior | Validation |
|---------|-----------|----------|---------------|------------|
| `sync` | -- | -- | writes `collection.db` | -- |
| `export` | required (xlsx/csv/json) | required | creates from scratch | extension = format |
| `update` | -- | required | reads | `.xlsx`, must exist |
| `deck import` | -- | required | reads | `.txt`, must exist |
| `deck export` | required (xlsx/json) | required | appends sheet to existing xlsx; creates json | extension = format |

XLSX is a disposable snapshot. The database is the single source of truth. User can recreate any file from DB at any time.

### Duplicate Deck Prevention

On `deck import`: check DB for existing deck with the same name. If found, show error and refuse to import. Prevents confusion with identically-named decks during export.

## Code Architecture

### `kards/cli.py` -- Typer declarations only

```python
import typer

app = typer.Typer(help="KARDS card collection manager")
deck_app = typer.Typer(help="Deck management")
app.add_typer(deck_app, name="deck")

@app.command()
def sync(): ...

@app.command()
def export(format: str, file: str): ...

@app.command()
def update(file: str): ...

@deck_app.command("import")
def deck_import(file: str): ...

@deck_app.command("export")
def deck_export(format: str, file: str): ...
```

### `kards/commands.py` -- business logic (extracted from current cli.py)

Functions:
- `sync_collection(db_path)`
- `export_collection(format, file, db_path)`
- `update_collection(file, db_path)`
- `import_deck(file, db_path)`
- `export_deck(format, file, db_path)`
- `_read_xlsx_quantities(filename)`
- `_select_deck(conn)`
- `validate_file(path, expected_ext, must_exist)` -- unified file validation

### `validate_file()` signature

```python
def validate_file(
    path: str,
    expected_ext: str,       # ".xlsx", ".txt", ".csv", ".json"
    must_exist: bool = False,
) -> Path:
```

Called per command:
- `export`: `validate_file(file, f".{format}")`
- `update`: `validate_file(file, ".xlsx", must_exist=True)`
- `deck import`: `validate_file(file, ".txt", must_exist=True)`
- `deck export`: `validate_file(file, f".{format}")`

## Error Handling

- Validation errors: Typer-style colored output, then exit
- Logging: informational progress messages only (`Sync completed`, `Deck imported`)
