# Repository Guidelines

## Project Structure & Module Organization
- `collection.py` is the CLI entrypoint (sync and export).
- `scrape.py` contains scraping and text normalization helpers.
- `storage.py` contains SQLite schema and queries.
- `exporters.py` handles XLSX/CSV/JSON exports.
- `tests/` contains pytest suites for CLI, storage, and text sanitization.
- `pyproject.toml` stores tool configuration (ruff, mypy, pytest) and dependencies.
- `Makefile` provides the standard dev commands used by this repo.
- Outputs are generated by `collection.py --export` (e.g., `kards_cards_ru.xlsx`).
- SQLite database is stored in `collection.db` (ignored by git).

## Build, Test, and Development Commands
- `uv sync` or `make sync`: install runtime deps and Playwright Chromium.
- `uv sync --all-extras` or `make sync-dev`: install dev tools (pytest, ruff, mypy).
- `uv run python collection.py --sync`: fetch cards into SQLite.
- `uv run python collection.py --export --format xlsx --file out.xlsx`: export from SQLite.
- `make run`: sync cards into SQLite.
- `make run-export-xlsx|run-export-csv|run-export-json`: export helpers.
- `make format`, `make lint`, `make typecheck`, `make test`: format, lint, type-check, and test.
- `make check`: run format + lint + typecheck + test.
- `make clean`: remove caches (`__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`).

## Coding Style & Naming Conventions
- Python 3.12+ with PEP 8 style; 4-space indentation; max line length 100 (ruff).
- All functions require type hints; mypy enforces `disallow_untyped_defs`.
- Import order: standard library → third-party → local; avoid wildcard imports.
- Prefer small, focused functions over heavy class hierarchies; avoid one-off abstractions.
- Use `logging` (not print) and catch specific exceptions.
- Code, comments, and docs are English only.

## Testing Guidelines
- pytest is the primary framework; async tests use pytest-asyncio.
- Test file pattern: `tests/test_<module_name>.py`.
- Test function pattern: `test_<function_name>_<scenario>()`.
- Target coverage is 80%+; run with `make test` or `uv run pytest tests/ -v --cov=. --cov-report=term-missing`.

## Commit & Pull Request Guidelines
- Commit format: `type: description` (e.g., `feat: add export filter`), present tense.
- Allowed types: `feat`, `fix`, `docs`, `test`, `refactor`, `config`, `chore`.
- Never include "Generated with Claude Code" in commit messages.
- PRs should describe changes, list tests run (ideally `make check`), add/update tests for new behavior, and update docs when user-facing behavior changes.
